# ycy-100Adults — 本地三通道蓝牙设备中继

把外部页面下发的速度 / 强度 / 档位信号，经本地后端映射后，通过浏览器 Web Bluetooth 控制三马达设备。

> 后端仅监听本机回环地址，不上传聊天记录或个人数据；默认预览模式，需手动武装才输出到硬件。

## 架构

```
外部页面（油猴桥接脚本） ─┐
房间 WS (rgate_client)   ├─→ state 闸门/映射 ─→ /ws/device ─→ relay.html (Web Bluetooth) ─→ 设备
手动面板 (/api/control)  ─┘
```

- **后端**：FastAPI（`backend/`），默认 `127.0.0.1:8799`。
- **中继页**：浏览器 Web Bluetooth 直连设备（主路径，Windows 上 Python bleak 直连易受蓝牙权限限制）。
- **桥接脚本**：油猴脚本，在已打开的页面读取 DOM 的速度段 / 强度 / 档位并转发本地（主取数通道）。

## 设备协议（V1.1）

- Service `FF40`，写 `FF41`（无响应写），通知 `FF42`。
- 帧：`0x35 | 命令字 | 载荷… | 校验和`，校验和 = 前面字节累加 `& 0xFF`。

| 命令 | 方向 | 帧 | 说明 |
|---|---|---|---|
| 0x10 | 主机→从机 | `35 10 <sum>` | 设备信息查询 |
| 0x11 | 主机→从机 | `35 11 <马达掩码> <模式> <sum>` | 固定模式；掩码 A=01 B=02 C=04，AB=03 ABC=07 |
| 0x12 | 主机→从机 | `35 12 <A> <B> <C> <sum>` | 实时强度，0 关 / 1–20 等级，数据改变才下发 |
| 0x13 | 从机→主机 | `35 13 01 <电量0-100> <sum>` | 电量上报 |

## 信号 → 强度映射

站点前端校验：BPM 合法值 `0`（停止）或 `20–300` 整数。本程序取有效下限 40、上限 300：

| BPM | 设备强度 |
|---|---|
| 0 / stop | 0（停止） |
| 20–39 | 1（最低有效档） |
| 40–300 | 每 20 一档，共 14 档，档位拉伸到 1 → 用户上限（设备量程 1–20） |

分档公式：`idx = clamp(floor((bpm - 40) / 20), 0, 13)`；`level = 1 + round(idx / 13 * (max_level - 1))`，再夹到 `0–用户上限`。

## 无数据保护（自动停止）

- 后端记录最后一次有效驱动指令（BPM / 档位 / 指令 / 手动强度）的时间戳；**超过 5 秒未收到新信号且仍有输出**，看门狗自动归零停止，不会保持上一次强度。
- 桥接脚本在页面连续读不到 BPM 时，主动上报 `bpm=0` 停止；后端看门狗作为掉线 / 页面关闭的兜底。
- 停止后需重新收到有效指令才会再次输出；急停（panic）仍需手动复位。

## 三通道来源绑定

外部可量化信号，可分别指定到 A/B/C 三个马达：

| 来源 key | 信号 | 取值 / 读法 | 映射 |
|---|---|---|---|
| `bpm` | 速度数值 | 0 / 20–300 | 14 档阶梯 → 1–上限 |
| `speed` | 速度段 | 6 个点，点亮个数 0–5（0=停止） | 线性拉伸到 1–上限 |
| `grip` | 强度点条 | 5 个点，点亮个数 0–4（0=停止）；或档位名 | 线性拉伸到 1–上限 |
| `level` | 档位按钮 | 1–9 | 线性映射 1–上限 |
| `off` | 关闭 | — | 该通道输出 0 |

- 点条读法：`<i class="on">` 个数即档数；例 `<i on><i on><i on><i><i>` = 强度 3 档。
- 默认绑定：A=速度段 speed、B=强度 grip、C=档位 level；可在中继页「通道来源」下拉调整并保存。
- 某通道所选来源暂无数据时，该通道归零（配合无数据看门狗）；不同通道互不覆盖。
- 若要三通道都跟速度数值，把 A/B/C 来源都选 `bpm` 即可。

### 通道档位偏移

每个通道可在映射强度上叠加一个独立偏移（中继页「通道来源」卡片，`-10` 偏弱 ~ `+10` 偏强，整数档）：

- 最终强度 = `clamp(映射强度 + 偏移, 0, 用户上限)`；映射为 0（停止 / 无数据 / 来源关闭）时偏移不把它抬高。
- 偏移只作用于信号映射链路；手动面板直接给定的强度不受偏移影响。

默认上限 20 时各档强度：

| BPM 区间 | 档 | 强度 |
|---|---|---|
| 40–59 | 1 | 1 |
| 60–79 | 2 | 2 |
| 80–99 | 3 | 4 |
| 100–119 | 4 | 5 |
| 120–139 | 5 | 7 |
| 140–159 | 6 | 8 |
| 160–179 | 7 | 10 |
| 180–199 | 8 | 11 |
| 200–219 | 9 | 13 |
| 220–239 | 10 | 14 |
| 240–259 | 11 | 16 |
| 260–279 | 12 | 17 |
| 280–299 | 13 | 19 |
| 300 | 14 | 20 |

站点内部 6 档锚点（备查，不参与线性映射）：

| 档位 | stop | vslow | slow | mid | fast | vfast |
|---|---|---|---|---|---|---|
| BPM | 0 | 40 | 60 | 100 | 140 | 180 |

level 按钮 1–9 线性映射到 1–上限；cmd `fast/slow/stop/go` 对当前强度单步增减 / 归零。

## 后端直连房间 WS（调试备选）

> 主取数走浏览器桥接脚本读 DOM；以下为后端直连 WS 的报文口径，供调试与 `probe_ws.py` 参考。

- 链接 hash 有两种格式，程序均自动识别：
  - 控制方：`#<room 32hex>.<controllerKey 32hex>`，`role=controller`
  - 被操控方：`#join.<room 32hex>.<playerKey 32hex>`，`role=player`
- 连接：`wss://<host>/rws/<room>?role=<player|controller>&key=<对应凭证>`，host 在 `backend/rgate_client.py` 的 `DEFAULT_HOST` 配置。
- 心跳：每 20s 发 `{"t":"ping"}`
- 下行报文：

| t | k 字段 | 含义 |
|---|---|---|
| state | bpm / drive / level / phase / paused | 房间状态快照 |
| drive | auto / stop / bpm | 实时速度指令 |
| bpm | bpm | 速度数值 |
| cmd | fast / slow / stop / go | 单步指令 |
| level | 1–9 | 档位 |

> 4000 关闭码 = 房间已结束 / 座位被占。需用**当前进行中**的房间链接；旧快照链接无法连上。

## 使用

1. 安装依赖（需 Python 3.10+）：
   ```powershell
   pip install -r requirements.txt
   ```
2. 启动后端：双击 `start.bat`（等价 `./start.ps1`），自动清理残留端口、起服务并打开中继页；停止双击 `stop.bat`。
   手动启动：`uvicorn backend.main:app --host 127.0.0.1 --port 8799`。
3. 桥接脚本：在 Tampermonkey / 暴力猴中新建脚本，粘贴 `bridge/remote_bridge.user.js` 全文并保存，按目标页面域名配置 `@match`；打开目标房间页面，脚本自动读取速度段 / 强度 / 档位并转发本地。
4. Chrome/Edge 打开 `http://127.0.0.1:8799/`，**武装（实机）** → **连接蓝牙设备**选设备；在「通道来源」卡片为 A/B/C 各选一路信号。
5. 后端 `/api/rgate/*` 直连房间 WS 仅作调试备选，中继页不提供连接入口。

### 打包产物（可选）

- `dist/ycy-100Adults.exe`：PyInstaller onefile 单文件，双击即起本地服务（127.0.0.1:8799），无需装 Python；页面资源已打入包内。
- 重新打包（需先 `pip install pyinstaller`）：在项目根目录执行
  ```powershell
  python -m PyInstaller --onefile --noconfirm --clean --name "ycy-100Adults" --add-data "web;web" run.py
  ```
- `run.py` 为打包入口；`ycy-100Adults.spec` 为生成的打包配置，可复构建。

## 使用注意

- 后端仅监听本机回环地址，不要把端口转发到公网。
- 默认预览模式（dry_run），需手动武装才输出到硬件；不用时及时解除武装或断开设备。
- 请从最低档开始，按需设置强度上限，避免长时间连续高输出；出现异常立即按下紧急停止。
- 本工具为本地设备控制演示框架，使用者自行承担使用方式与后果。
